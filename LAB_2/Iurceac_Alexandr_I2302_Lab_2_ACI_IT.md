## Задание 1. CLI-ассистент: приветствие, валидация и мини-отчёт

### Условие

Создать скрипт `cli_assistant.sh`, который:

* запрашивает имя пользователя и его отдел/группу (опционально),
* проверяет, что имя введено (до 3 попыток),
* выводит системный отчёт: дата, имя хоста, аптайм, свободное место на `/`, число пользователей,
* завершает работу строкой приветствия.

### Код скрипта

📄 *cli_assistant.sh*

```bash
#!/bin/bash
MAX_TRIES=3

ask_input() {
    local prompt="$1"
    local input=""
    local tries=0
    while [[ $tries -lt $MAX_TRIES ]]; do
        read -rp "$prompt: " input
        if [[ -n "$input" ]]; then
            echo "$input"
            return 0
        fi
        ((tries++))
        echo "Поле не может быть пустым. Попробуйте снова. ($tries/$MAX_TRIES)"
    done
    echo "Превышено число попыток. Выход."
    exit 1
}

NAME=$(ask_input "Введите ваше имя")
read -rp "Введите ваш отдел/группу (можно оставить пустым): " DEPT
[[ -z "$DEPT" ]] && DEPT="не указан"

DATE=$(date '+%Y-%m-%d %H:%M:%S')
HOSTNAME=$(hostname)
UPTIME=$(uptime -p)
FREESPACE=$(df -h / | awk 'NR==2 {print $4}')
USERS=$(who | wc -l)

echo "===== Системный отчёт ====="
echo "Дата: $DATE"
echo "Хост: $HOSTNAME"
echo "Аптайм: $UPTIME"
echo "Свободное место на /: $FREESPACE"
echo "Пользователей в системе: $USERS"
echo "==========================="
echo "Здравствуйте, $NAME ($DEPT)!"
```

## Задание 2. Резервное копирование каталога с логированием и ротацией

### Условие

Написать скрипт `backup_rot.sh`, который:

* принимает каталог-источник и (опционально) каталог для бэкапов,
* проверяет входные данные,
* создаёт архив с меткой времени,
* пишет лог в `backup.log` с временем, размером архива и кодом возврата.

### Код скрипта

📄 *backup_rot.sh*

```bash
#!/bin/bash
SRC="$1"
DST="${2:-$HOME/backups}"
LOGFILE="$DST/backup.log"

if [[ -z "$SRC" ]]; then
    echo "Ошибка: не указан источник" >&2
    exit 1
fi
if [[ ! -d "$SRC" ]]; then
    echo "Ошибка: $SRC не каталог" >&2
    exit 1
fi

mkdir -p "$DST" || { echo "Не удалось создать $DST"; exit 1; }

BASENAME=$(basename "$SRC")
TS=$(date '+%Y%m%d_%H%M%S')
ARCHIVE="backup_${BASENAME}_${TS}.tar.gz"
ARCHIVE_PATH="$DST/$ARCHIVE"

tar -czf "$ARCHIVE_PATH" -C "$(dirname "$SRC")" "$BASENAME"
STATUS=$?

if [[ $STATUS -eq 0 ]]; then
    SIZE=$(du -h "$ARCHIVE_PATH" | cut -f1)
else
    SIZE=0
fi

echo "$(date -Iseconds) SRC=\"$SRC\" DST=\"$DST\" FILE=\"$ARCHIVE\" SIZE=$SIZE STATUS=$STATUS" >> "$LOGFILE"
exit $STATUS
```

📸 *Скриншот 2 — запуск скрипта*
📸 *Скриншот 3 — содержимое backup.log*

## Задание 3. Мониторинг дискового пространства

### Условие

Создать скрипт `disk_monitor.sh`, который:

* принимает путь и порог заполнения (по умолчанию 80%),
* проверяет существование пути,
* выводит процент использования и статус: `OK` или `WARNING`,
* возвращает код возврата (0 — норма, 1 — превышен порог, 2 — ошибка).

### Код скрипта

📄 *disk_monitor.sh*

```bash
#!/bin/bash
PATH_TO_CHECK="$1"
THRESHOLD="${2:-80}"

if [[ -z "$PATH_TO_CHECK" ]]; then
    echo "Ошибка: не указан путь" >&2
    exit 2
fi
if [[ ! -d "$PATH_TO_CHECK" ]]; then
    echo "Ошибка: $PATH_TO_CHECK не существует" >&2
    exit 2
fi

USAGE=$(df -h "$PATH_TO_CHECK" | awk 'NR==2 {print $5}' | tr -d '%')

DATE=$(date '+%Y-%m-%d %H:%M:%S')
echo "$DATE"
echo "Путь: $PATH_TO_CHECK"
echo "Использовано: ${USAGE}%"

if (( USAGE < THRESHOLD )); then
    echo "Статус: OK"
    exit 0
else
    echo "Статус: WARNING: диск почти заполнен!"
    exit 1
fi
```
